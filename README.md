# 本地简历填充助手

网申表格一页几十个空格，每次都要重填一遍姓名、电话、学校、专业、起止时间。这个 Chrome 扩展
（Manifest V3）让你点一下就把这些填上，并且**只在你自己点击之后**才动手。

它不会自动打开网页，不会替你点提交、保存、下一步或上传，也不会把任何资料发到网络上。所有资料
只存在这台电脑的浏览器里。密码和验证码一律跳过；证件号码虽然能填，但**永远不会自动勾选**——要填
得你自己在那一行打勾。

当前发布版本：`0.3.0`。本次更新增加了网页字段筛选、批量选择、定位到网页控件、资料速查复制、更多
招聘网站字段别名和手动填写身份证号的受控流程；敏感字段仍不会默认选择或被网站记忆。

- 许可证：MIT（见 `LICENSE`）
- 无 `host_permissions`：只在你点击时读当前这一页，不会在后台到处翻页面

## 三分钟上手

### 第一步：装上扩展

两种拿法，选一种：

**A. 别人给你的压缩包（推荐给同学）**

1. 把 `简历填充助手.zip` 解压到一个文件夹，比如 `D:\简历填充助手`。
   解压出来应该直接看到 `manifest.json`、`popup.html` 这些文件——**不要再嵌套一层文件夹**。
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选中第 1 步解压出来的那个文件夹。
5. 工具栏上出现一个蓝色表格图标，就是它。

**B. 直接从本仓库加载**

和第 1 步一样，只是"解压出来的文件夹"换成这个仓库文件夹本身。

> Chrome 只能加载**文件夹**，不能直接加载 zip，所以必须先解压。这一步省不掉。

### 第二步：把你的资料填进模板，再导进扩展

1. 打开 **`模板文件.txt`**（和 zip 放在一起的那个文件）。
2. 把它**复制一份**到你自己的文件夹再填。
   **不要直接改原文件**——留一份空白模板，以后发给同学还能用；而且原文件要留在仓库里。
3. 用记事本打开你复制的那份，把每一行等号**后面**改成你自己的信息。等号前面不要动。
4. 保存后，点扩展图标，点 **导入资料**，选中你刚填好的那个文件。

**填模板只有三条规则：**

| 规则 | 说明 |
| --- | --- |
| `#` 开头的整行是说明 | 扩展会忽略，你可以随便删 |
| 等号后面**留空**就是"不填" | 网页上那一栏会保持空白，不会乱猜 |
| 不要删掉 `[basic]` 这种方括号段落名 | 扩展靠它认字段 |

不确定的项**直接留空**就行，不会出错。想加第二条教育经历，把整个 `[education.1]` 段落复制一份、
段落名改成 `[education.2]` 即可，里面的字段名不用动。

> 不需要一条条填满。先把姓名、电话、邮箱、学校、专业填上，就能应付大多数网页了，剩下的以后慢慢补。

### 第三步：在网申页面填表

1. 打开要填的招聘页面。
2. 点扩展图标，点 **看看这页要填什么**。
3. 检查列出来的每一项，改掉不对的、取消不想填的。
4. 点 **帮我填上**。

扩展只改字段的值，不点提交、不保存、不点下一步、不上传。

## 分发和更新

### 给别人一个包：`简历填充助手.zip` + `模板文件.txt`

发给同学的是**两个东西**：

| 文件 | 是什么 |
| --- | --- |
| `简历填充助手.zip` | 扩展本体。解压出来就能加载，里面**只有程序**，没有任何个人信息、模板和测试 |
| `模板文件.txt` | 空白模板。让同学复制一份填好自己的资料，再用"导入资料"导入 |

打包命令（改完代码后运行）：

```powershell
.\tools\pack.ps1
```

脚本会重新生成 zip，并自动检查：`manifest.json` 必须在压缩包根目录（保证解压后可直接加载）、
图标必须在、里面不能有个人信息、不能有模板和测试文件。任何一条不满足就直接报错。

### 更新自己（或同学）已经装好的扩展

**资料不会丢。** 判定资料归属的是扩展 ID，而 ID 由 `manifest.json` 里的 `key` 字段固定，所以只要
不换这个 key，无论从哪个文件夹加载，都是同一个扩展、同一份资料。

1. 拿到新版 zip，**解压覆盖到原来那个文件夹**（不要解压成一个新文件夹）。
2. 打开 `chrome://extensions`，找到"简历填充助手"，点 **重新加载**。
3. 刷新已经打开的招聘页面。

如果确实需要从新文件夹加载：先加载新版（ID 相同，资料自动还在），确认无误后再删掉旧的副本。如果
浏览器里出现了两个同名扩展，删掉资料为空的那个即可。

> 从没有 `key` 的旧版本第一次升级过来时，ID 会变一次，资料需要手动搬一次：在旧扩展里点 **导出资料**，
> 切到新扩展点 **导入资料**。此后 ID 永久固定，不再需要这一步。

升级到新版本后，请先刷新已经打开的招聘页面，再点"看看这页要填什么"。扩展也会在扫描和填充前检查
页面里的脚本版本，并尝试注入最新版。

## 把模板发给别人用

`模板文件.txt` 是一份**完全空白、不含任何个人隐私**的模板，可以放心直接发给同学。

他们拿到之后：复制一份 → 填好 → 用同样的"导入资料"按钮导入即可。模板里已写好每一项的中文解释
和格式要求（比如"身高只填数字，不要带 cm"、"日期写 2024-09 或 2024-09-01"），不需要另外看文档。

所以发给同学的就是**一个 zip + 一个 `模板文件.txt`**，不需要额外说明。

## 每一项右边的标签是什么意思

| 标签 | 意思 | 要不要管 |
| --- | --- | --- |
| `已对上` | 找到了对应的资料 | 不用管，默认会填 |
| `请确认` | 名字只对上一半，拿不准 | 看一眼对不对，对就勾上 |
| `资料里没有` | 你的资料里没这一项 | 见下面"遇到资料里没有的项" |
| `不会保存` | 像是密码或验证码 | 不保存，也不填 |

手动改过某一项的填充内容后，这一项会自动勾上。

## 遇到"资料里没有"的项

有些栏目你的资料里确实没有对应内容（例如网页问"学习经历"，而你的资料里叫"教育经历"）。这种情况下
卡片里有一个下拉框，写着"它其实是…（选一个）"，从里面选出它真正对应的内容，扩展就会把资料里对应
的值填进去，并记住这层关系。

下拉框里都找不到合适的，就点"都不是，我自己起个名"，展开后给它起个名字即可（已经帮你填好了网页上
的叫法，直接确认也行）。

无论走哪条路，**只需要做一次**：记住之后，以后所有网站出现同样的叫法都能自动认出来。

## 同义词与自动学习

不同招聘网站对同一个字段的叫法不一样：教育经历可能写成"学校经历"，期望职位可能写成"意向岗位"，
自我评价可能写成"个人陈述"。扩展用两层来处理。

**第一层是内置别名表。** 常见叫法直接写在扩展里，目前约 380 个词条，覆盖各大招聘网站对同一栏目的
不同叫法：

- 姓名类的"姓名 / 名字 / 真实姓名 / 本人姓名 / 申请人姓名 / 中文姓名"；
- 联系方式类的"联系电话 / 手机号码 / 电话号码 / 联系手机 / 移动电话""邮箱 / 电子邮箱 / 电子邮件 / 邮箱地址 / 电子信箱"；
- 身高体重类带单位的写法"净身高(cm) / 身高（cm）""体重(kg) / 净体重"——栏目名后面的括号会被忽略，所以带不带单位都能对上；
- 各分区特有的叫法，例如"荣誉名称 / 奖项名称 / 获奖名称""项目名称 / 课题名称""活动名称""担任职务 / 学生职务"。
  **"荣誉名称"只会对上荣誉，"项目名称"只会对上项目，不会串到"姓名"**；
- 附加信息里的"兴趣爱好 / 业余爱好""受处分情况 / 有无处分""学术专著 / 论文著作""专利成果 / 发明专利"等。

还有两条规则让更多叫法能自动对上：

- **栏目名前面的限定词会被忽略。** 国聘把教育经历写成"最高学历院校""最高学历毕业时间""最高学历专业分类"，
  去掉"最高学历"之后就是你熟悉的"院校""毕业时间""专业分类"。所以带这类前缀的栏目也能对上，同时不影响
  单独出现的"最高学历"（它对应的是学历）。
- **拉丁文缩写只在词边界上匹配。** 网页控件的内部名称（例如 `name="gpAbroad"`）里恰好含有 `gpa`，
  但那是命名巧合、不是栏目叫法，扩展不会据此把绩点填进"是否海外留学"栏。

这一层不需要你做任何事。

**第二层是它自己学。** 内置表再全也列不完所有写法，所以扩展会记住你的判断，有两种方式：

1. **确认模糊匹配。** 一个字段显示为"请确认"时，你勾选它并点击填充，扩展就记下「这个标签 = 那个字段」。
2. **指明认不出的项是什么。** 一个栏目完全没匹配上（标签显示"资料里没有"）时，卡片里有一个下拉框
   "它其实是…（选一个）"，从中选出它真正对应的内容（例如"学习经历"其实是"教育经历 · 学校"）。选中后
   扩展会从你的资料里取出对应内容填进去，并记住这层关系。

两种方式记住的结果是一样的：下次任何网站出现同样的叫法，都会直接当成"已对上"并默认勾选。选错了
可以点"换成别的"重新选。

有些叫法扩展会**故意不猜**，因为它们本身有歧义或带了公司名：带具体公司名的题目（"是否有应聘过 ××
公司下属子公司"）每个企业都不一样，"联系方式"可能指电话也可能指邮箱。这类词会显示成"请确认"，
你确认一次之后就记住了。

- 学习结果是**全局**的，不按网站区分——「意向岗位」在哪里都是同一个意思，没必要每个网站教一遍。
- 同一个词在不同网站上含义不同时（例如"联系方式"有的站指电话、有的站指邮箱），扩展会同时记住两种
  对应，各自都能命中；如果记错了，按下一段的方法删掉即可。
- 只存在本地浏览器里，不联网。
- 学习只在**你确认过**之后发生。扩展不会自己猜着记，也不会因为某次填充就修改你的资料。

想看看它学会了什么，或者删掉记错的一条：点"导出资料"，里面会有 `[label_mappings.N]` 段落，形如

```
[label_mappings.1]
label=意向岗位
profile_key=intention.1.target_role
updated_at=2026-09-11T08:00:00.000Z
```

删掉不想要的段落再"导入资料"即可。已确认的写法即使删除也不会影响其他功能，只是那一处会回到"待确认"。

> **导出和模板是两个不同的文件，别弄混：**
> 空白模板叫 `模板文件.txt`（发给人填的，跟安装包一起分发），导出的是 `简历资料导出.txt`
> （你自己资料的备份）。名字故意不一样，这样导出时不会把你的模板覆盖掉。
> 两个文件格式相同，**导入框都能读**，所以导出后想手改再导回去也完全可以。

## 模板里都有什么字段

`模板文件.txt` 里的每一项都带中文注释，这里只说明需要特别注意的地方。

- **基本信息**：姓名、性别、出生日期、年龄、参加工作时间、工作经验、民族、籍贯、政治面貌、婚姻状况、
  户口所在地、生源地、现居住地、通信地址、联系电话、手机类别（区号）、邮箱、微信、QQ、证件类型与证件号码、
  有无子女、紧急联系人和紧急联系电话、身高、体重。
  **证件号码可以填，但永远不会自动勾选。** 它属于敏感信息：扫描时能对上，但默认不打勾，也不会被
  “网站记忆”记下来——要填请自己在那一行打勾。密码和验证码则完全跳过，不认也不填。
- **求职意向**：期望职位、期望行业、期望城市、期望薪资、工作性质、可到岗时间、面试站点。
- **教育经历**：学校、学院、起止年月、学制、学历、招生类型、学习形式、应届往届、学位证、学位名称、
  专业、第二专业、专业分类、专业排名、绩点、英语等级与成绩、研究方向、导师、毕业论文题目、课程和描述等。
  重复的本科记录会按学校、学历、专业和起止年月自动合并。
- **附加信息**：自我评价之外的那些自由填写和是非题——兴趣爱好、特长、受处分情况、学术专著、专利成果、
  是否有违法违纪、是否应聘过本公司、是否有亲友在本公司工作、是否有手术史或重大疾病史、校园大使推荐码。
  这些题目在各大招聘网站上反复出现，所以单独留了位置，不用每次现填。
- **网申问答**：很多网申表格会问"你最看重什么"这类开放题，写在 `[application_answers.N]` 里可以自动填。
- **工作 / 实习、项目经历、荣誉奖励、实践活动、校内职务、技能证书**：各一个段落，需要多条就复制段落。

**身高和体重请只填数字**（例如 `height=178`、`weight=75`）。网页上的栏目名通常已经写明"净身高(cm)"
"体重(kg)"，把单位一起写进值里（`178CM`）会导致数字输入框拒绝这个值。

**日期两种精度都支持**：`YYYY-MM`（例如 `2024-09`）和 `YYYY-MM-DD`（例如 `2024-09-18`）。资料编辑器里
的"开始时间 / 结束时间 / 获得时间"是普通输入框，两种写法都能填；写成 `2024/9/18`、`2024.9.18` 这类
写法会在输入框失焦时自动规范成 `2024-09-18`，月份和日期不足两位会补零。格式不对（例如写成"2024年9月"）
时输入框会变红并给出提示——这种值扩展不会识别，属于静默失效，所以值得当场发现。

需要在网页上填写"日"的场景，只有模板里带了具体日值才会填。如果网页把日期拆成"年 / 月 / 日"三个
下拉、而模板只写到月份，扩展会保留"日"为空，不会擅自填 1 号。

**还没填完也没关系。** 留空的项、以及写成"请填写""待补充"这类占位词的项，都会被当成"没有值"，
网页上保持空白，绝不会把"请填写"三个字填进你的手机号栏。

## 自定义字段和网站记忆

扫描页面时，你的资料里没有对应内容的栏目会显示为"资料里没有"。如果它不属于任何已有内容，可以点
"都不是，我自己起个名"，填上名称、显示成什么、归到哪一类，再点"记住这一项"，扩展就会按网站记住它。
之后你在这个网站上填的普通文本、下拉和单选内容都会自动存下来，下次再打开这一页时会作为建议值出现，
仍然需要你点"帮我填上"才会写入。

密码、验证码、身份证、银行卡、安全码和文件选择字段不会自动保存。扩展不会向第三方网页注入新的表单
控件，也不会点击提交、保存、下一步、投递或上传。

## 界面

界面按 WinUI 3（Windows 11）的设计语言实现，颜色、字阶和控件形态都取自 WinUI 3 的资源命名
（`TextFillColorPrimary`、`ControlFillColorDefault`、`AccentFillColorDefault`）。所有样式和图标都是
本地资源，不加载任何网络字体或图标库——MV3 的内容安全策略不允许，扩展也不该为此联网。

- **资料编辑器**采用 NavigationView 布局：左侧导航栏列出全部资料分类，可点左上角按钮收起到图标栏；
  强调色在导航栏底部切换，共 8 个预设色，选择结果保存在本地。
- **弹窗**里的字段列表、按钮、输入框与编辑器保持同一套令牌。文本框聚焦时底边变为强调色下划线
  （WinUI 的 TextBox 惯例），按钮和输入框底部描边更深（WinUI 的 elevation border），"记住此字段"是
  ToggleSwitch 样式。
- 强调色只存一个基准色，悬停与按下状态由 CSS `color-mix()` 从它派生。浏览器不支持时回退到固定的蓝色梯度。
- 界面目前只有浅色主题。

第一次打开时资料是空的，弹窗会提示先去导入模板或打开资料编辑器填写。

## 图标

工具栏、扩展管理页和详情页用的都是 `icons/` 下的同一套图标：蓝色圆角方块（与界面强调色同一色相）+
白色表格 + 对勾，表示"把表格填好"。只有图形没有文字，所以在任意语言环境下都能用。

- `icons/icon.svg` 是矢量原图，供文档和商店素材使用。
- `icons/icon-{16,32,48,128}.png` 是 Chrome 实际加载的位图，由 `tools/make_icons.py` 生成（8 倍超采样后
  Lanczos 缩放，16px 下线条依然干净）。**改动图标请改脚本再重新生成，不要直接编辑 PNG。**
- `manifest.json` 的 `icons` 和 `action.default_icon` 都指向这四个文件；`verify-extension.ps1` 会校验文件
  存在且尺寸与文件名一致。

## 控件支持

- 文本框、文本域、原生下拉、单选框、复选框。
- Ant Design / Element / iView / select2 这类自定义下拉：会先展开，按选项文本点击，再回读控件确认页面
  状态确实变了，没变则报失败而不是假装成功。
- 复选框组：模板写 `周一、周三` 时会勾选命中项，并取消同组其他项，重复填充结果一致。
- 只有一个复选框时按 `是/否` 设置勾选状态，也接受 `有/没有`、`同意/不同意`、`接受/不接受`、
  `true/false`、`1/0`、`√/×`；此时写"否"会明确取消勾选。
- 日期：网页把年 / 月 / 日拆成多个下拉时，只有模板里写全 `YYYY-MM-DD` 才会填"日"。
- 同源 iframe：表单嵌在同源框架里时会一起扫描和填充。跨域 iframe 需要给扩展加 host 权限，本扩展故意
  不申请，因此跨域框架里的表单不会被处理。

## 测试

需要 Node.js。冒烟测试还需要一个 Chromium 浏览器（Chrome / Edge / Brave 都行）。在本目录执行：

```powershell
node --test 测试/*.test.js
.\测试\verify-extension.ps1
.\测试\chrome-smoke.ps1
.\测试\appform-smoke.ps1
.\测试\dynamic-smoke.ps1
.\测试\frame-smoke.ps1
.\测试\options-smoke.ps1
.\测试\popup-smoke.ps1
.\测试\load-smoke.ps1
.\测试\pack-smoke.ps1
```

- `node --test` 和各 `*-smoke.ps1` 只使用 `测试/` 下的合成夹具，不会读取真实简历。
- `verify-extension.ps1` 检查清单、权限、图标尺寸、固定 key、空白模板是否真的空白、zip 里有没有混进
  不该有的东西，并反向确认仓库里没有出现真实个人信息。**缺 `personal-values.local.txt` 时会跳过个人
  信息扫描**，所以在别人机器上也能跑通。
- `pack-smoke.ps1` 是唯一验证"交付格式"的测试：它会重新打包、按用户的方式解压、然后把解压出的文件夹
  真正加载进浏览器，确认 `manifest.json` 在压缩包根目录、图标齐全、扩展 ID 仍是固定值（更新不丢资料）。
- 浏览器路径不写死：脚本会依次找环境变量 `RESUME_TEST_BROWSER`、`测试/browser.local.txt`（本机覆盖，
  已被 git 忽略）和常见安装路径。
- `load-smoke.ps1` 和 `pack-smoke.ps1` 的浏览器加载部分需要较旧的 Chromium，因为 Chrome 137 起会忽略
  `--load-extension`。找不到可用浏览器时它们会明确提示并跳过那一半检查，而不是报失败。
- 测试产生的浏览器配置、页面转储等临时文件都写在 `测试/输出/`，已被 git 忽略，不会进仓库也不会进 zip。

### 只在本机运行的额外检查

`测试/verify-local-profile.ps1` 会读取你的 `resume-profile.txt`，检查它能被解析、导出结果稳定、不含
附件分区，并且没有任何占位词会被误填。它**已被 git 忽略**，因为里面写着你的个人特征值。

反向扫描用的对照词表是 `personal-values.local.txt`（同样已被 git 忽略）。**这张表越全，隐私防护越严密**——
把你的学校、学院、专业、导师、单位都写进去，以后任何文件里不小心带上这些词都会立刻被检查拦下。

如果要在 GitHub 上公开这个仓库，请确认下面这些文件**没有**被提交：

```
resume-profile.txt                    # 你的真实资料
简历模板信息文件.txt                   # 你填好的模板（旧命名）
简历资料导出.txt                       # 「导出资料」下载下来的备份
personal-values.local.txt             # 用于反向扫描的个人特征值
测试/verify-local-profile.ps1          # 含个人特征值的本地检查
测试/browser.local.txt                 # 本机浏览器路径覆盖
测试/输出/                             # 测试产生的临时文件
tmp/                                  # 你抓下来研究用的页面等
```

`.gitignore` 已经全部覆盖，且 `verify-extension.ps1` 每次都会替你确认一遍。
**注意 `模板文件.txt` 不在这个列表里**——它是空白模板，必须提交，也是要发给同学的那份。
