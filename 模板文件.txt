# ============================================================
#  简历模板信息文件
# ============================================================
#
#  怎么用：
#    1. 把本文件复制一份到你自己的文件夹，留着这份空白版以后还能用。
#    2. 把每一项等号【后面】的内容改成你自己的。等号前面不要动。
#    3. 打开插件弹窗，点「导入资料」，选中你填好的这个文件。
#    4. 以后想改，改这个文件再导入一次就行。
#
#  三条规则：
#    · 以 # 开头的整行只是说明，插件会忽略，你想删掉也可以。
#    · 等号后面留空的项，插件就不会填，网页上保持空白。不确定的项就留空。
#    · 不要删掉 [basic] 这种方括号段落名，插件靠它认字段。
#
#  想加第二条教育经历：把整个 [education.1] 段落复制一份，段落名改成
#  [education.2] 即可，里面的字段名不用改。其他段落同理。
#
#  本文件不含任何真实个人信息，可以直接发给别人用。
#
