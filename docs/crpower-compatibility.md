# 华润电力兼容检查

检查材料：用户保存的“简历操作”页面、资源目录和七张投递过程截图。原始文件及个人值均未收录到仓库。

| 截图问题 | 原因 | 修复及边界 |
| --- | --- | --- |
| 专业选择弹窗 | 普通文本写入不会确认网页专业分类 | 展开弹窗、精确选择并确认，回读页面；无完全对应分类时提示手动确认，不猜近似专业 |
| 证件类型、国籍/地区 | 嵌套 Ant 下拉与搜索框重复识别；国籍资料模型缺项 | 保留单个有效下拉、新增国籍资料；国籍不默认填写，不将含义不唯一的“中国”代选为某地区 |
| 专业排名 | “前20%”与“5%-20%”含义不同，子串匹配可能误选 | 精确区间或确定百分位单个区间可选，多个候选或范围不一致时拒绝 |
| 绩点成绩 | GPA、GPA满分与宽泛“成绩”匹配存在混淆 | 只读取该教育记录的 GPA，缺失时不借用满分；未知学校换算标准不自动转换 |
| 实习经历为空 | 分区标题被上层“上传简历”覆盖；实习描述缺别名 | 按分区和记录筛选工作/实习资料，补实习标签；无资料时留空 |
| 亲属关系错误 | 公司有无亲属的问题与家属身份共用了标签；没有独立记录约束 | 家庭栏目只使用对应家属记录，新增家属生日；“父亲/母亲”不填成“是/否” |
| 重复记录、日期和省市选择 | 同名无 ID 字段定位到第一条；旧版 Ant 日期和双下拉需要组件确认 | 指纹带分区及记录编号、回读独立字段；日期通过日历点击，省市资料采用“省/市”格式 |
